# 신규 공학 계산 도구 60개 · E101~E160 배포 기록

기록일: 2026-10-25. 우주·천체·양자·역학·재료·유체·전자·신호·열·화학·제조 분야의 계산기 60개를 독립 공개 GitHub 저장소와 Pages로 배포했습니다. `ko·en·es·zh·ja·de` 6개 언어, 신규 360개 페이지입니다. 기존 100개를 합치면 160개 앱·960개 페이지입니다.

## 검증

- 독립 기준값·입력과 출력 단위·정의역·특수 경우·언어 구조를 포함한 Node 명명 테스트 1,563개 통과. 반복 입력이 필요한 계산기는 행 추가·삭제와 행별 검증을 갖습니다.
- 신규 360개 언어 페이지를 320px·1280px Chromium viewport에서 실행한 720건 통과. 기본 계산·오입력·언어 오류·가로 넘침·언어 링크·More Apps를 검사했습니다. 테스트 파일과 화면 실행 증거의 소스 지문을 현재 공개 파일 지문과 대조했습니다.
- GitHub `Calculator checks` CI 60개 성공. 각 Pages 최신 빌드의 커밋이 로컬 clean HEAD 및 푸시 커밋과 일치합니다.
- 공개 360페이지의 언어·제목·canonical·hreflang·게시자 태그를 확인했습니다. 언어 설정·자체 제작 대표 이미지·앱·단위·스타일·사이트맵·엔진과 모든 모델 모듈을 검증본과 대조했습니다.
- 브라우저 검증은 Chromium 기반입니다. 실물 휴대전화와 모바일 Safari 검증을 포함하지 않습니다. 코드 존재 확인은 Analytics 수집·AdSense 노출 성공 증명과 구분합니다.

## 구현 원본과 권리

도구 설정과 다국어 원본은 `tool.json`, `localization/*.json`, `src/template.html`에 있습니다. `scripts/build-locales.py`로 정적 페이지를 재생성합니다. 계산은 브라우저에서 실행하며 번역 API를 런타임에 호출하지 않습니다. 반복 자료는 사용자가 행을 추가·삭제해 입력하고, 계산 조건과 물성·보정계수의 의미는 각 앱에서 명시합니다.

코드·설명·예제·아이콘·대표 이미지를 직접 작성했습니다. 외부 교재 본문·도판·사진·계산기 코드나 유료 물성 데이터베이스를 복제하지 않았습니다. 참고한 수학·물리 공식과 상수의 원문 링크는 각 앱 `SOURCES.md`에 기록하며 외부 폰트 파일을 재배포하지 않습니다. 자체 코드는 MIT 라이선스이고, 공급자 분석·광고 스크립트는 별도 권리를 따릅니다. 외부 원어민 감수는 포함하지 않습니다.

GTM `GTM-NV2WWQXB`, GA4 `G-2ZYSF0173P`, AdSense `ca-pub-9767176956440077`, Cloudflare Web Analytics 코드와 우측 하단 작은 회색 `More Apps` 링크를 적용했습니다. 링크는 `https://nanalab.kr/apps/`입니다.

## 사이트맵과 본사이트 반영

앱별 `sitemap.xml`은 6개 URL과 언어 대체 링크를 갖는 leaf `urlset`입니다. 통합 `engineering-tools-locale-sitemap.xml`은 기존 600개와 신규 360개, 총 960개 URL을 중복 없이 합친 자료입니다. `published_at`은 GitHub 저장소 최초 생성 시각을 사용합니다. 기존 100개 카드 행·게시 시각·반영 상태를 보존했습니다.

`UpdateQue.md` 원문을 보존하고 신규 한국어 대표 카드 60개와 개별 앱 사이트맵 60개 연결 요청을 추가했습니다. 본사이트의 루트 sitemapindex 및 카드 반영은 별도 대기 상태이며 이 문서만으로 완료 처리하지 않습니다. 문서 커밋 후 SHA가 바뀐 앱은 해당 SHA의 CI·Pages·공개 파일을 재검증하고 현재 audit 기록을 갱신해야 합니다. 공개 docs 복사본에는 복사 당시의 검증 시점을 명시합니다.
